# 🎬 Movie Explorer

A small React project that fetches movie data from the [TMDB API](https://www.themoviedb.org/).  
Users can **browse popular movies**, **search by title**, and **click a movie for more details**.  
This project was built to practice working with APIs and filtering data in React.

---

## 🚀 Run Locally

1. Clone the project:
   git clone https://github.com/yourusername/movie-explorer.git
   npm install
2. Create a .env file in the root with your TMDB API key:
   REACT_APP_TMDB_API_KEY=your_api_key_here
3. Start the app
   npm start
